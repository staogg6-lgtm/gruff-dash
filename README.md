# Gruff Dash

Web game wrapped as an Android app with Capacitor. GitHub Actions builds the APK.

1. Edit `appId` in capacitor.config.json (must be unique, e.g. com.yourname.gruffdash).
2. Push to GitHub. Open the Actions tab, run "Build Android APK".
3. When it finishes, download "gruff-dash-apk" from the run page (it is a zip containing app-debug.apk).
